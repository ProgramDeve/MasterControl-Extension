## 📋 Descripción

**Master Control** es una extensión todo-en-uno para Chrome que centraliza herramientas esenciales para desarrolladores, administradores de sistemas y usuarios avanzados.

| Módulo | Función |
|--------|---------|
| 🌐 **IP Tracker** | Muestra IP real con bandera, geolocalización y proveedor |
| 🔍 **IP Search** | Consulta cualquier IP (país, ciudad, ISP, coordenadas) |
| ⏰ **Alarm System** | Recordatorios con sonido personalizado y notificaciones |
| 📋 **Text Snippets** | Guarda textos frecuentes y cópialos con un clic |
| 🔐 **Proxy Manager** | Configura, guarda y prueba proxies por país |

---

## ✨ Características

### 🌐 IP Real
- Visualización instantánea de tu IP pública
- Bandera del país y ubicación geográfica
- Proveedor de internet (ISP)

### 🔍 Buscador de IP
- Consulta cualquier dirección IP
- Información detallada: país, ciudad, región, ISP
- Valida formato de IP automáticamente

### ⏰ Sistema de Alarmas
- Programa recordatorios con hora específica
- Sonido personalizado al momento del evento
- Notificaciones del sistema
- Ventana de alerta con animación

### 📋 Gestor de Plantillas
- Guarda textos, correos o códigos frecuentes
- Copia con un clic al portapapeles
- Persistencia de datos

### 🔐 Proxy Manager
- **Proxy Activo**: Configuración en tiempo real
- **Proxies Guardados**: Biblioteca de proxies por país
- **Test de conexión**: Verifica cada proxy antes de usarlo
- **Soporte**: HTTP, HTTPS, SOCKS4, SOCKS5

### 📌 Extra
- Botón de desactivación rápida de proxy
- Ventana flotante independiente
- Interfaz oscura con acentos dorados
